Rakz's Calculator

A modern, responsive calculator web application built using HTML5, CSS3, and Vanilla JavaScript as part of the CodeAlpha Web Development Internship – Task 2.

Features

- Basic arithmetic operations
- Decimal calculations
- Clear and Delete functions
- Keyboard support
- Division-by-zero handling
- Multiple consecutive calculations
- 6 customizable color themes
- Theme persistence using LocalStorage
- Responsive design
- Button animations
- No "eval()" used

Technologies Used

Technology| Purpose
HTML5| Structure and semantic markup
CSS3| Styling, responsive design, animations, and themes
Vanilla JavaScript| Calculator logic and interactions
LocalStorage| Theme persistence

Keyboard Controls

Key| Action
"0–9"| Numbers
"+"| Addition
"-"| Subtraction
"*" / "x"| Multiplication
"/"| Division
"."| Decimal
"Enter" / "="| Calculate
"Backspace"| Delete
"Escape" / "C"| Clear

How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open "index.html" in a browser.

Optional: Use VS Code with the Live Server extension.
